📖 V2Ray Configuration Guide

Configure your V2Ray client with the following SOCKS5 settings:

  • Address: 127.0.0.1
  • Port: 1819
  • Protocol: SOCKS5
  • No authentication required.

Example `config.json` for V2Ray:

{
  "inbounds": [
    {
      "protocol": "socks",
      "settings": {
        "auth": "noauth",
        "udp": true,
        "ip": "127.0.0.1",
        "port": 1819
      }
    }
  ],
  "outbounds": [
    {
      "protocol": "freedom",
      "settings": {}
    }
  ]
}

Aether Control is a visual desktop frontend made by Mahan07dev for the Aether project – a powerful network tunneling and obfuscation tool. This interface simplifies the process for beginners by providing an interactive UI, real‑time status monitoring, and one‑click connection management, while the underlying Aether binary does all the heavy lifting.

Aether base-code is developed and maintained by CluvexStudio. This frontend application is an independent companion app made by Mahan07dev for those who need an easier approach.
